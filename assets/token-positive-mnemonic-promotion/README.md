# Token-Positive Mnemonic Promotion Assets (`assets/token-positive-mnemonic-promotion`)

## Purpose

This directory owns the immutable contracts and campaign inputs for the
[token-positive mnemonic promotion plan](../../60-planning/04-token-positive-mnemonic-promotion/README.md).
The campaign re-registers the exact historical R2 surface as P1 without
changing the original compact-projection experiment.

## What belongs here

- Closed schemas and machine-readable decision rules.
- Exact R2 reference identities and prospective P0/P1 roles.
- Fresh corpus, power, profile, schedule, prompt, and resource inputs added by
  their numbered implementation sections.

Generated observations and evidence belong under the ignored
`build/token-positive-mnemonic-promotion/` tree. No asset in this directory
authorizes a model call.
