# Token-Positive Mnemonic Promotion Confirmatory Corpus (`assets/token-positive-mnemonic-promotion/corpus`)

## Purpose

This directory contains the 48 prospective, representation-neutral semantic
cases for comparing readable P0 with exact-R2 P1. The cases are content-
separated from all 24 effectful-source and 48 compact-projection design cases.

## What belongs here

- Balanced semantic descriptors and neutral answer oracles.
- Blinded exclusion and replacement history fixed before registration.
- Same-prefix, negation, numeric-value, irrelevant-context, and prompt-
  injection coverage without representation labels or answer leakage.

## Maintaining this index

Keep the semantic case as the independent unit, record every pre-registration
exclusion or replacement, and never resize or edit the corpus after a model
observation.
