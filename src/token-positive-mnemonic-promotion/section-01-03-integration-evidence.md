# Token-Positive Mnemonic Promotion Section 1.3 Integration Evidence

## Prospective design closure

One clean ERTS workflow validates and reconciles the exact P0/P1 contract and
R2 references, paired case-cluster power audit, 48 fresh semantic cases, two
model profiles, two tokenizer profiles, four prompt protocols, 1,536 primary
schedule cells, 3,072-request hard ceiling, traceability boundary, and eleven
closed JSON Schemas. The 21-file Phase 1 registration digest is
`e7804254acc846c8e5ec83ac959c3f3d7fc8ea321209a26bd0b7cfcc4ded4c5b`.

Two independent clean-process writes produce identical canonical JSON. The
evidence records zero hosted calls, zero efficacy observations, and disabled
network authorization. It therefore closes only the prospective design; it
does not satisfy Phase 2 P1/R2 conformance, offline token qualification, or
any model-fidelity decision.

## Design evidence boundary

The traceability record labels the earlier 72-case compact-projection results
as candidate-selection and threshold-design evidence only. It retains the
reported R0 versus R2 document totals—17,204 versus 15,703 under
`cl100k_base`, and 17,118 versus 15,755 under `o200k_base`—and the associated
8.72% and 7.96% savings. Those observations authorize neither a new model-
fidelity claim nor reuse of the prior corpus as the new confirmatory sample.

## Mutation evidence

The BEAM mutation campaign detects all 19 named defects. Scientific-role
mutants cover historical R2 promotion, a second candidate, R2 reference and
conformance drift, relaxed token thresholds, pooled-family inference,
pseudoreplication, fidelity-before-token ordering, and a hidden weighted
score. Design mutants cover power and schedule seed drift, reused corpus
semantics, condition leakage, family imbalance, missing schedule cells,
expanded replacements, exact-profile drift, and prompt asymmetry.

The integration suite also confirms that every trusted Phase 1 tool resolves
to a `.beam` module and that no foreign trusted source enters the stream-owned
implementation directory.

## Tests and reproduction

```bash
make test-mnemonic-phase-1
```

This offline command compiles all Phase 1 modules, runs 29 EUnit tests, writes
the complete preregistration evidence twice, requires byte-identical outputs,
executes all schema, scope, corpus, schedule, profile, traceability, and
mutation checks, and performs no network, provider, or model call. Generated
artifacts remain below ignored `build/token-positive-mnemonic-promotion/`.
